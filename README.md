A program that sums up the world news of Tuesday 17 November 2026 in one image: a newspaper front page led by the Ukrainian strike that collapsed a span of the Crimea Bridge, with Iranian drones over Bahrain, the Shenzhen summit, Japan's jet scramble, the Geneva killer-robot talks and the day's other big stories. It writes the image to /output/entry.png. The picture itself (entry.png) is drawn at build time by generate.py; main.py is standard-library only and copies it into place.

## Run it

```sh
python3 main.py
```
